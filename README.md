# Visit Anatolia

> Turkey Travel Experts for Tailor-Made Journeys & Private Experiences.

Visit Anatolia is a bespoke travel and destination management platform showcasing luxury private tours, Biblical heritage journeys, Gulet cruises, and cultural odysseys across Istanbul, Cappadocia, Ephesus, and the Turkish Riviera.

---

## 🚀 Features

- **Tailor-Made Trip Planner**: Interactive multi-step itinerary planner and inquiry engine.
- **Curated Journeys**: Detailed itineraries for cultural, luxury, and special-interest travel.
- **Biblical Heritage Tours**: Dedicated itineraries covering the Seven Churches of Revelation, Footsteps of St. Paul, and early Christian Anatolia.
- **Interactive Destination Guides**: Region filters, highlight modals, and rich visual storytelling.
- **B2B / Travel Advisor Portal**: Dedicated resources for international travel agents and tour operators.
- **Fast, Lightweight Architecture**: Built with modern Vanilla JS and Vite for maximum speed and optimal SEO.

---

## 🛠️ Tech Stack

- **Bundler / Dev Server**: [Vite](https://vitejs.dev/)
- **Core**: Vanilla JavaScript (ES Modules)
- **Styling**: Modern CSS Design System (CSS Custom Properties, Glassmorphism, Micro-interactions)
- **Hosting**: [Vercel](https://vercel.com/) (configured with `vercel.json`)

---

## 💻 Getting Started Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```

---

## 🌐 Deploy to Vercel

This repository is pre-configured for seamless deployment to Vercel:

1. Import this repository into [Vercel Dashboard](https://vercel.com/new).
2. The framework preset is automatically detected as **Vite**.
3. Build command: `npm run build`
4. Output directory: `dist`
5. Click **Deploy**.

All SPA routing rules and asset rewrites are handled automatically via [`vercel.json`](./vercel.json).
